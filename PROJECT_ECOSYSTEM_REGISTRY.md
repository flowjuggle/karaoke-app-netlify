# Flow Juggle / PTIV Shared Project Intelligence

This project participates in the Flow Juggle / PTIV ecosystem. Before major work, consult the canonical registry:

https://docs.google.com/document/d/1UsqCXhIwUYqcoyfVmOoPThU9YkMWKoSUC4uDA_K-Dqg

## Required workflow
- Discover sibling-project solutions before rebuilding.
- Reuse validated components, datasets, assets, and failure lessons with provenance.
- Branch radical departures and preserve known-good production/rollback points.
- Keep catalog identity, playback availability, and deployment state as separate gates.
- Require real rendered-state verification before calling UX work complete.
- Feature-detect device/browser capabilities and permission-gate sensors/files/accounts.
- Promote consequential wins and failures back into the shared registry so other projects learn from them.

When adding reusable work, record: project, date, source/version/branch, problem, what worked, what failed, test evidence, reusable lesson/component, sibling projects that should adopt it, risks, and rollback point.
